# Keller Adapt — Next.js Web Experience

Interactive sensory environments, assistive therapy gear, and developmental tools designed to empower children and neurodivergent communities.

## Overview
Built with Next.js (App Router), Three.js, and authentic Framer interactive shaders.
- **Hero & Interactive Fluid Mask**: Custom WebGL fluid distortion shaders reacting to pointer interactions.
- **Problem & Emotional Reality**: Full-width high-contrast interactive cards highlighting clinical shortages, caregiver fatigue, and sensory overload challenges.
- **Product Category Showcase**: Dynamic multi-product categories with full-bleed imagery and realistic fluid hover reveal effects.
- **Responsive Architecture**: High performance CSS & SVG layouts optimized for mobile, tablet, and desktop viewports.

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or whichever port Next.js assigns) in your browser.

## Tech Stack
- Next.js 15
- React 19
- Three.js
- Framer Motion
- TypeScript
